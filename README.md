# تخته‌خانه

آموزش تعاملی تخته‌نرد به فارسی با HTML، CSS و JavaScript. برای شروع، فایل `index.html` را در مرورگر باز کنید یا [نسخهٔ آنلاین](https://prp-e.github.io/backgommon-tutorial/) را بازی کنید.

- **تمرین و آموزش** شامل هفت درس است و با چیدن مهره‌های روشن شروع می‌شود. تاس‌های تمرینی ثابت‌اند تا بتوانید هر موقعیت را دوباره امتحان کنید.
- **بازی دونفره** روی یک دستگاه، با تاس تصادفی، تک‌بازی یا مسابقهٔ ۳، ۵ و ۷ امتیازی اجرا می‌شود. قوانین مکعب دوبل، مارس، برد سه‌امتیازی و کرافورد اجرا می‌شوند.
- برای حرکت، ابتدا خانهٔ مهره یا خط وسط را انتخاب کنید و سپس مقصد یا دکمهٔ خروج را بزنید. مقصدهای مجاز روی تخته مشخص می‌شوند. دکمه‌ها با صفحه‌کلید هم قابل استفاده‌اند.
- مبنا [قوانین استاندارد تخته‌نرد](https://usbgf.org/backgammon-basics-how-to-play/) است. قواعد اختیاری بازی پولی، مانند جاکوبی و بیور، در این بازی استفاده نمی‌شوند.

آزمون‌های موتور بازی را با `node --test rules.test.js` اجرا کنید.

در آیفون، بازی را در سافاری باز کنید و از منوی اشتراک‌گذاری «Add to Home Screen» را بزنید. پس از یک بار بارگذاری کامل، بازی و درس‌ها آفلاین هم قابل اجرا هستند.
